# Automated PDF Sales Report Generator

This project automatically generates a professional PDF sales report from CSV data.

## Features
- Reads structured sales data from CSV
- Calculates:
  - Total revenue
  - Average revenue
  - Top-performing product
  - Best-performing month
- Generates a formatted PDF report automatically

## Technologies Used
- Python
- pandas
- reportlab

## Input Format
CSV file with columns:
Month, Product, Revenue

## Output
sales_report.pdf containing summarized business insights.

## How to Run
Install dependencies:
pip install pandas reportlab

Run:
python pdf_report_generator.py
